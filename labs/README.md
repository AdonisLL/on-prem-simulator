# Participant labs

Complete the modules in order. Each module has an observable checkpoint before
the next one starts.

| Module | Outcome |
|---|---|
| [00 - Prerequisites](00-prerequisites/README.md) | Tools, permissions, region, cost, and teardown readiness confirmed |
| [01 - Deploy source](01-deploy-source/README.md) | Private Windows source estate is running and validated |
| [02 - Configure appliance](02-configure-migrate-appliance/README.md) | Appliance is registered and the selected physical-server or Hyper-V discovery path is configured |
| [03 - Discover and assess](03-discover-and-assess/README.md) | Server, IIS, and SQL assessments reviewed and exported |
| [04 - Analyze dependencies](04-analyze-dependencies/README.md) | Web-to-SQL dependency evidence captured |
| [05 - Copilot assessment](05-copilot-modernization-assessment/README.md) | Evidence-driven modernization plan created without deploying the target |

Portal labels and Microsoft appliance downloads change independently of this
repository. Use the linked Microsoft Learn procedures when a screenshot or label
differs; do not bypass a current prerequisite to match an old screenshot.
